Verzweigungen

BefehlBeschreibung
 
if note <= 4:
    print("bestanden")
elif note == 5:
    print("Nachprüfung")
else:
    print("nicht bestanden")
Verzweigung. elif (else if) und else sind optional, elif darf mehrfach vorkommen.
Wichtig: Doppelpunkt am Zeilenende und Einrückung (4 Leerzeichen) für den Block!
match befehl:
    case "start":
        starten()
    case "stop":
        stoppen()
    case _:
        print("unbekannt")
Mehrfachauswahl (ab Python 3.10), ähnlich switch in C. case _ fängt alle übrigen Fälle ab.

ZeroDivisionErrorDivision durch 0
IndexErrorListenindex existiert nicht, z. B. liste[10] bei 3 Elementen

Beispielprogramm

import random

geheim = random.randint(1, 100)
versuche = 0

while True:
    try:
        tipp = int(input("Dein Tipp (1-100): "))
    except ValueError:
        print("Bitte eine ganze Zahl eingeben.")
        continue

    versuche += 1
    if tipp < geheim:
        print("Zu klein!")
    elif tipp > geheim:
        print("Zu groß!")
    else:
        print(f"Richtig! Du hast {versuche} Versuche gebraucht.")
        break
