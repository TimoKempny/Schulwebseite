Grundgerüst

#include <stdio.h>

int main(void)
{
    printf("Hallo Welt\n");
    return 0;
}
TeilBeschreibung
#include <stdio.h>Bindet die Bibliothek für Ein-/Ausgabe ein (standard input/output).
int main(void)Hauptfunktion – hier startet jedes C-Programm.
{ ... }Geschweifte Klammern fassen Anweisungen zu einem Block zusammen.
;Jede Anweisung endet mit einem Semikolon.
return 0;Beendet main; 0 bedeutet „ohne Fehler beendet“.
// Kommentar
/* mehrzeilig */		Kommentare werden vom Compiler ignoriert.

Eingabe mit scanf

BefehlBeschreibung
scanf("%d", &zahl);Ganzzahl einlesen. Das & (Adresse) vor der Variablen nicht vergessen!
scanf("%lf", &wert);double einlesen – hier ist %lf Pflicht (%f nur für float).
scanf(" %c", &zeichen);Einzelnes Zeichen einlesen. Das Leerzeichen vor %c überspringt den übrig gebliebenen Zeilenumbruch.
scanf("%19s", name);Wort einlesen (bis zum Leerzeichen), höchstens 19 Zeichen. Bei Arrays kein &.
fgets(zeile, 100, stdin);Ganze Zeile inkl. Leerzeichen einlesen (max. 99 Zeichen + \0). Der Zeilenumbruch bleibt im String.
if (scanf("%d", &n) != 1) {
    printf("Keine Zahl!\n");
}
scanf gibt zurück, wie viele Werte erfolgreich gelesen wurden – damit lassen sich Fehleingaben erkennen.

Verzweigungen

BefehlBeschreibung
 
if (note <= 4) {
    printf("bestanden\n");
} else if (note == 5) {
    printf("Nachpruefung\n");
} else {
    printf("nicht bestanden\n");
}
Verzweigung. Bedingung in runden Klammern, Block in geschweiften Klammern. else if und else sind optional.
switch (wahl) {
    case 1:
        printf("Start\n");
        break;
    case 2:
        printf("Stopp\n");
        break;
    default:
        printf("Unbekannt\n");
}
Mehrfachauswahl für ganze Zahlen und Zeichen. Ohne break läuft das Programm in den nächsten case weiter! default fängt alle übrigen Fälle ab.

Schleifen

BefehlBeschreibung
 
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
Zählschleife: for (Start; Bedingung; Schritt). Hier läuft i von 0 bis 4.
while (zahl < 0) {
    scanf("%d", &zahl);
}
Kopfgesteuerte Schleife: Bedingung wird vor jedem Durchlauf geprüft.
do {
    printf("Zahl (1-10): ");
    scanf("%d", &zahl);
} while (zahl < 1 || zahl > 10);
Fußgesteuerte Schleife: läuft mindestens einmal – ideal für Eingabeprüfungen. Semikolon am Ende!
break;Schleife sofort verlassen
continue;Rest des aktuellen Durchlaufs überspringen

Beispielprogramm

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    int geheim, tipp = 0, versuche = 0;

    srand(time(NULL));
    geheim = rand() % 100 + 1;

    do {
        printf("Dein Tipp (1-100): ");
        if (scanf("%d", &tipp) != 1) {
            printf("Bitte eine ganze Zahl eingeben.\n");
            while (getchar() != '\n');   /* Eingabepuffer leeren */
            continue;
        }
        versuche++;

        if (tipp < geheim) {
            printf("Zu klein!\n");
        } else if (tipp > geheim) {
            printf("Zu gross!\n");
        }
    } while (tipp != geheim);

    printf("Richtig! Du hast %d Versuche gebraucht.\n", versuche);
    return 0;
}
