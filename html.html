HTML-Merkhilfe

Die wichtigsten Tags zum Nachschlagen – vom Grundgerüst bis zur Seitenstruktur.

HTML-Grundgerüst Textstrukturierung Bilder einbinden Hyperlinks Tabellen Seitenstrukturierung CSS einbinden Attribute für IDs und Klassen

HTML-Grundgerüst

<!DOCTYPE html>
<html lang="de">
  <head>
    <meta charset="UTF-8">
    <title>Titel der Seite</title>
  </head>
  <body>
    Inhalt der Seite
  </body>
</html>

Textstrukturierung

TagBeschreibung
<h1>Überschrift</h1>
<h2>Überschrift</h2>		Überschrift (heading). Die Zahl gibt die Ordnung an, von h1 bis h6.
<p>Absatz</p>Absatz (paragraph)
<br>Zeilenumbruch (break)
<ul>
  <li>Punkt 1</li>
  <li>Punkt 2</li>
</ul>
Unnummerierte Liste mit Aufzählungszeichen
(unordered list mit list items)
<ol>
  <li>Punkt 1</li>
  <li>Punkt 2</li>
</ol>
Nummerierte Liste (1., 2., …)
(ordered list mit list items)

Bilder einbinden

TagBeschreibung
<img src="bild" alt="text">Bild einbinden (image). src ist der Pfad zur Bilddatei (source), alt der Alternativtext.

Hyperlinks

TagBeschreibung
<a href="ziel">Linktext</a>Link. href gibt die verlinkte Seite an. Linktext ist der Text, der im Browser angezeigt wird.

Tabellen

TagBeschreibung
 
<table>
  <tr>
    <th>Z1</th>
    <th>Z2</th>
  </tr>
  <tr>
    <td>Z3</td>
    <td>Z4</td>
  </tr>
</table>
Tabelle.
tr (table row) umschließt eine Zeile.
th (table header) umschließt eine Überschrift für eine Zeile/Spalte.
td (table data) umschließt eine normale Zelle.
<td colspan="2">...</td>Attribut für th und td: colspan (column span) – Zelle überspannt mehrere Spalten.
<td rowspan="2">...</td>Attribut für th und td: rowspan (row span) – Zelle überspannt mehrere Zeilen.

Seitenstrukturierung

TagBeschreibung
<header>...</header>Kopfbereich einer Seite (≠ head)
<nav>...</nav>Navigationsbereich einer Seite
<main>...</main>Haupt-Inhaltsbereich einer Seite
<footer>...</footer>Fußbereich einer Seite
<div>...</div>Allgemeine Box ohne inhaltliche Bedeutung

CSS einbinden

TagBeschreibung
<link rel="stylesheet" href="style.css">CSS-Datei einbinden (im head!). href gibt den Pfad zur CSS-Datei an.
<style> ... </style>style-Block im head einer HTML-Datei. Regeln werden so geschrieben wie in der CSS-Datei.
<p style="color: red;">...</p>style-Angaben direkt am HTML-Tag. Es sind auch mehrere Angaben möglich!

Attribute für IDs und Klassen

AttributBeispielErklärung
id<div id="foo">...</div>Mit dem Attribut id weist man einem Element eine ID zu.
class<div class="bar">...</div>Mit dem Attribut class weist man einem Element eine oder mehrere Klassen zu.
