## Lokal bearbeiten

Repo einmalig klonen:

```bash
git clone git@github.com:TimoKempny/Schulwebseite.git
cd Schulwebseite
```

Änderungen veröffentlichen:

```bash
git pull
git add .
git commit -m "Beschreibung der Änderung"
git push
```

Nach dem Push ist die Seite in 1–2 Minuten aktualisiert.

## Hinweise

- Dateinamen und Pfade sind case-sensitive (`Bild.JPG` ≠ `bild.jpg`).
- Pfade relativ angeben (`css/style.css`, nicht `/css/style.css`).
